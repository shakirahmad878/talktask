# Project Instructions — TalkTask

## Mandatory Pre-Execution Explanation & Approval Protocol
Before executing any modifications, shell commands, dependency installations, migrations, or builds:

1. **Exact Reasons**: Clearly state what was observed and what needs to be done.
2. **Why It Happened**: Detail the root cause or reason behind the situation.
3. **How It Will Be Solved**: Outline the exact, concrete steps and code/command changes planned.
4. **Approval Gate**: Stop and wait for explicit user approval. Do NOT execute any changes until the user approves.
